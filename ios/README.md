# CosmosMap for iPad

A native iPad app (iPadOS 26.0 or later) that wraps the CosmosMap web build in a full-screen `WKWebView`.
It is free, has no login or in-app purchases, and does no tracking.

- Bundle ID `com.wodo.cosmosmap`, team `AH277897AV`, display name **CosmosMap**
- iPad only (`TARGETED_DEVICE_FAMILY=2`); no Mac Catalyst, no "Designed for iPad" on Mac or visionOS
- Needs iPadOS 26, which is the first release where WebGPU works in `WKWebView`

## Layout

```
ios/
  CosmosMap.xcodeproj            generated by scripts/generate_xcode_project.rb (committed)
  CosmosMap/
    App/                         SwiftUI app, WKWebView wrapper, server lifecycle
    Server/                      loopback HTTP/1.1 server + /api proxy (Network.framework)
    Resources/Info.plist
    Resources/PrivacyInfo.xcprivacy
    Assets.xcassets              AppIcon (single 1024 px) + LaunchBackground colour
    Web/                         copy of dist/ (gitignored, made by scripts/sync-web.sh)
  CosmosMapTests/                unit + loopback integration tests for the server
  ExportOptions.plist            App Store Connect upload (manual signing)
  scripts/
    generate_xcode_project.rb
    sync-web.sh
```

## Build

Run these from the repository root:

```sh
npm ci && npm run build                 # produces dist/
ios/scripts/sync-web.sh                 # rsync --delete dist/ into ios/CosmosMap/Web/
ruby ios/scripts/generate_xcode_project.rb   # only after adding/removing Swift files or changing settings
open ios/CosmosMap.xcodeproj
```

`Web/` is added to the app as a folder reference, so the `dist/` directory tree lands unchanged at `CosmosMap.app/Web/`.
If `Web/index.html` is missing, the "Check bundled web build" build phase fails the build.

### Older Xcode (local only)

Xcode 16 and the iOS 18 SDK can build the project if you override the deployment target:

```sh
# Build (generic destination: xcodebuild won't list iOS 18 simulators for a 26.0 project)
xcodebuild -project ios/CosmosMap.xcodeproj -scheme CosmosMap -configuration Debug \
  -destination 'generic/platform=iOS Simulator' -derivedDataPath ios/build/DerivedData \
  IPHONEOS_DEPLOYMENT_TARGET=18.0 CODE_SIGNING_ALLOWED=NO build

# Tests need a concrete simulator, so generate a temporary 18.0 project, then regenerate it at 26.0 before committing.
COSMOSMAP_DEPLOYMENT_TARGET=18.0 ruby ios/scripts/generate_xcode_project.rb
xcodebuild -project ios/CosmosMap.xcodeproj -scheme CosmosMap \
  -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M4)' \
  -derivedDataPath ios/build/DerivedData CODE_SIGNING_ALLOWED=NO test
ruby ios/scripts/generate_xcode_project.rb
```

WebGPU is not available in `WKWebView` on iOS 18. There the page loads and the web app shows its own "WebGPU Not Available" overlay.

## Release

- Debug uses automatic signing.
- Release uses manual signing: `Apple Distribution` with the profile **CosmosMap App Store**.
- `MARKETING_VERSION` is 1.0. CI sets `CURRENT_PROJECT_VERSION` on each upload.

```sh
npm ci && npm run build && ios/scripts/sync-web.sh
xcodebuild -project ios/CosmosMap.xcodeproj -scheme CosmosMap -configuration Release \
  -destination 'generic/platform=iOS' -archivePath build/CosmosMap.xcarchive \
  CURRENT_PROJECT_VERSION=<build number> archive
xcodebuild -exportArchive -archivePath build/CosmosMap.xcarchive \
  -exportOptionsPlist ios/ExportOptions.plist -exportPath build/export
```

`ExportOptions.plist` settings: `method app-store-connect`, `destination upload`, `manageAppVersionAndBuildNumber false`, `uploadSymbols true` and `stripSwiftSymbols true`.

## How it works

### Local server (`Server/`)

- `NWListener` is bound to `127.0.0.1` only. It first tries the fixed port **41873**; if that port is taken, it uses an ephemeral port.
- The port is fixed so the page origin stays the same across launches. The web app's `localStorage` (for example the Horizons cache) is keyed by origin.
- If iOS reclaims the socket while the app is suspended, the listener restarts on the same port.
- Serves `Web/` with:
  - the correct MIME types
  - HEAD requests
  - single `Range` requests (206/416)
  - ETag/304
  - `Cache-Control: no-cache` (`no-store` for `index.html`)
  - COOP `same-origin` and COEP `require-corp`, like `server/index.mjs`
  - keep-alive
  - files streamed in 256 KB chunks
- Paths without an extension that are not under an asset prefix fall back to `index.html` (SPA routing). Misses under an asset prefix return 404.
- Path traversal is blocked in three steps:
  1. The path is decoded once, and any `..`, NUL or backslash segment is rejected.
  2. The remaining segments are joined onto the root.
  3. The resolved real path must still be inside `Web/`.
- `/api/*` (GET, HEAD and OPTIONS) is proxied to `https://cosmosmap.org/api/*`:
  - The query string is forwarded unchanged.
  - Status, Content-Type, Cache-Control, Retry-After, ETag and Last-Modified pass through.
  - The timeout is 15 s.
  - Network failures return `503 {"error":"offline"}`.
- `acceptLocalOnly` is deliberately **not** set. In the simulator it resets every loopback connection.

### Web view

- The page loads from `http://127.0.0.1:<port>/`. Loopback is a secure context, and the page is cross-origin isolated (both checked at runtime in Debug).
- `window.CosmosMapNative = { platform: "ipad", version: "1.0 (N)" }` is injected at document start.
- Navigation to anything other than the local origin opens in Safari. This covers `target=_blank`, `window.open` and `mailto:`.
- If the WebContent process is killed, the page reloads.
- Back/forward swipe gestures, link previews and bounce are off, and there are no automatic content insets.
- `isInspectable` is enabled in Debug only.
- The status bar is hidden and the home indicator auto-hides. The dark `LaunchBackground` colour (#06060F) sits behind everything, so the screen never flashes white.

### Privacy

- `PrivacyInfo.xcprivacy` declares no tracking, no collected data and no required-reason APIs.
- The server avoids file-timestamp and UserDefaults APIs: file size comes from `FileHandle.seekToEnd()`, and ETags are built from size plus build number.
